## Purpose

The Define phase pins down the job, the success criteria and the failure modes before anyone writes a prompt, including whether AI is needed at all.

## Usage

**Example:**
```
/ai-define helpbot
```

## Prerequisites

None — this is the first phase.

## What It Does

<Steps>
<Step>Reads research, support and analytics artifacts for users and agreed metrics</Step>
<Step>Describes the job: user, moment, input, output, next step</Step>
<Step>Checks whether a rule, search or form would do the job instead</Step>
<Step>Writes success criteria a check could test, and the failure modes with their harm</Step>
<Step>Sets latency and cost budgets</Step>
<Step>Writes `.singularskills/ai/<project>/01-define.md`</Step>
</Steps>

## Output

<Output>
Creates `.singularskills/ai/<project>/01-define.md` containing:

- Job
- Is AI the right tool?
- Success criteria
- Failure modes
- Budgets
</Output>
