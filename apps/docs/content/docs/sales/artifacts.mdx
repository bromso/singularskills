## Phase Artifacts

| Phase | File | What It Contains |
|-------|------|-----------------|
| Qualify | `01-qualify.md` | Fit, MEDDPICC with known, assumed or unknown labels, people identified or engaged, no-decision risk, recommendation |
| Discovery | `02-discovery.md` | Calls, the buyer's pains as quotes, their metrics, decision criteria and process, buying committee, gaps |
| Solution | `03-solution.md` | Pains to capabilities, the value case (computed or illustration), proof plan, fit gaps |
| Proposal | `04-proposal.md` | The proposal draft, and an internal For approval list |
| Close plan | `05-close.md` | Go-live date, mutual action plan, paper process, risks, give-get |
| Review | `06-review.md` | Outcome, the seller's and buyer's accounts, causes rated by buyer evidence, lessons |

Re-running Qualify or Discovery first keeps the previous file under its date. A later discovery call adds a dated section to the same file.

## Playbook Artifacts

| Skill | File | What It Contains |
|-------|------|-----------------|
| ICP | `playbook/icp/<date>-<slug>.md` | Evidence, segments, profile, qualification criteria |
| Pipeline Review | `playbook/pipeline/<date>-<slug>.md` | Checks, deals needing attention, forecast, actions |
| Win-Loss | `playbook/win-loss/<date>-<slug>.md` | Seller and buyer reasons, the gap, the price check, changes |

`/sales-call-prep`, `/sales-follow-up` and `/sales-objection` write no file.

## People

A deal's files may name the buyer's contacts and their roles as you supply them, and nothing private. Playbook files use deal or company names only, and quotes drop people's names.
