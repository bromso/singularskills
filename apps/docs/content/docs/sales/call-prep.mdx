## Purpose

The Call Prep skill prepares the goal, agenda, attendees, questions and the next step to ask for.

## Usage

**Example:**
```
/sales-call-prep [deal]
```

## Prerequisites

The deal's artifacts, when they exist.

## What It Does

<Steps>
<Step>Sets the call's one goal</Step>
<Step>Lists attendees and what each cares about</Step>
<Step>Writes open questions for the deal's unknowns</Step>
<Step>Names the next step to ask for</Step>
</Steps>

## Output

<Output>
Returns the prep in chat. Writes no file.
</Output>
