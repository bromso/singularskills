## Purpose

The Objection skill finds what may lie behind a concern before answering it, never with pressure or misrepresentation. Not for the team's guide; see `/marketing-sales-enablement`.

## Usage

**Example:**
```
/sales-objection [deal] <objection>
```

## Prerequisites

The objection and the deal's context.

## What It Does

<Steps>
<Step>Lists possible concerns behind it</Step>
<Step>Writes questions to ask first</Step>
<Step>Drafts responses grounded in the deal's facts</Step>
</Steps>

## Output

<Output>
Returns the questions and responses in chat. Writes no file.
</Output>
