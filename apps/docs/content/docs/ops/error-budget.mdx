## Purpose

The Error Budget skill works out the budget in time and requests, each alert's threshold, and the time to exhaustion.

## Usage

**Example:**
```
/ops-error-budget <target> <window>
```

## Prerequisites

The SLO target and window.

## What It Does

<Steps>
<Step>Computes the budget</Step>
<Step>Computes thresholds and budget consumed per alert window</Step>
<Step>Computes time to exhaustion at a burn rate</Step>
</Steps>

## Output

<Output>
Returns the numbers and the script in chat. Writes no file.
</Output>
